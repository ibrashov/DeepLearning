# Задача 3 — правило цепочки для сигмоидного нейрона

Исходный код: [`task3.py`](task3.py)

## Что сделано

Реализован один нейрон с сигмоидной активацией и квадратичной ошибкой. Производные loss по весу `w` и смещению `b` найдены вручную по правилу цепочки, а затем проверены центральными конечными разностями.

## Фокус обучения

- прямой проход нейрона;
- sigmoid;
- квадратичная ошибка;
- локальные производные;
- правило цепочки и backpropagation;
- gradient checking.

## Вычислительный граф

```text
z = wx + b
a = sigmoid(z)
L = (a - y)²
```

```text
dL/dw = dL/da · da/dz · dz/dw
dL/db = dL/da · da/dz · dz/db
```

Выполняет прямой проход. `L` далее не используется, но распаковывается для полноты.


Производная `(a-y)²` по `a` равна `2(a-y)`.

```python
    da_dz = sigmoid(z) * (1-sigmoid(z))
```

Вычисляет производную sigmoid: `σ(z)(1-σ(z))`. Можно было использовать уже вычисленное `a`: `a * (1-a)`.

```python

```

Производная `wx+b` по `b` равна единице.

```python

```

Производная `wx+b` по `w` равна входу `x`.

```python
    dL_dw = dL_da * da_dz * dz_dw
```

По правилу цепочки получает производную loss по весу.

```python
    dL_db = dL_da * da_dz * dz_db
```

По правилу цепочки получает производную loss по смещению.

```python
    return dL_dw, dL_db
```


Объявляет численную проверку обеих производных.

```python
    w_minus = w-h
    w_plus = w+h
    b_minus = b-h
    b_plus = b+h
```

Создаёт значения веса и смещения, сдвинутые на `h` в обе стороны.

```python
    _, _, L_w_minus = forward(w_minus, b, x,y)
    _, _, L_w_plus = forward(w_plus, b, x,y)
```

Считает loss при уменьшенном и увеличенном весе. `_` показывает, что `z` и `a` не нужны.

```python
    _, _, L_b_minus = forward(w,b_minus, x,y)
    _, _, L_b_plus = forward(w,b_plus, x,y)
```

Так же получает два loss для смещения, не меняя вес.

```python
    grad_w = (L_w_plus - L_w_minus)/(2*h)
```

Находит численную производную по `w` центральной разностью.

```python

```

Находит численную производную по `b`.


## Как понимать знак градиента

Оба градиента отрицательны. Для уменьшения loss градиентный спуск вычитает градиент, поэтому `w` и `b` увеличатся. Тогда `z` и sigmoid-выход приблизятся к целевому `y = 1`.
