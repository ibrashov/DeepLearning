# Задача 4 — формы массивов и матричное умножение

Исходный код: [`task4.py`](task4.py)

## Что сделано

Одна и та же линейная модель запускается с весами двух разных форм: `(2,)` и `(2, 1)`. Числа в предсказаниях одинаковы, но формы результата отличаются: `(4,)` и `(4, 1)`. Это демонстрирует, почему формы массивов важны в NumPy и машинном обучении.

## Фокус обучения

- форма массива (`shape`);
- различие вектора и матрицы-столбца;
- матричное умножение `@`;
- влияние формы весов на форму результата;
- предупреждение ошибок broadcasting.

## Формы

```text
X:             (4, 2)
w:             (2,)
X @ w:         (4,)

w_bad:         (2, 1)
X @ w_bad:     (4, 1)
```

Название `w_bad` не означает, что матрица-столбец всегда неправильна. Она плоха именно для ожиданий этого примера, где нужен одномерный результат `(4,)`.

## Код построчно

```python
import numpy as np
```

Подключает NumPy.

```python
x = np.array([
    [1.0, 2.0],
    [2.0, 0.5],
    [3.0, 1.0],
    [4.0, 3.0],
])
```

Создаёт матрицу признаков. Каждая из четырёх строк — объект, каждый из двух столбцов — признак. Форма равна `(4, 2)`.

```python
y = np.array([1.0, 3.0, 5.0, -2.0])
```

Создаёт правильные ответы формы `(4,)`. В этой задаче они не используются, но понадобятся в следующей для MSE.

```python
w = np.array([2.0, -1.0])
```

Создаёт одномерный вектор из двух весов с формой `(2,)`.

```python
b = 0.5
```

Задаёт скалярное смещение модели.

```python
def predict(x,w,b):
```

Объявляет функцию линейного предсказания.

```python
    return x @ w + b
```

Умножает все строки `x` на веса и добавляет к каждому результату смещение `b`.

```python
yaht = predict(x,w,b)
```

Получает предсказания формы `(4,)`. Имя, вероятно, задумано как `yhat`, то есть `ŷ`.

```python
print(" yaht shape:", yaht.shape)
```

Печатает форму обычных предсказаний.

```python
print("yaht:", yaht)
```

Печатает значения `[0.5, 4.0, 5.5, 5.5]`.

```python
w_bad = w.reshape(2,1)
```

Меняет форму весов с `(2,)` на `(2, 1)`, то есть превращает вектор в матрицу-столбец.

```python
yaht_bad = predict(x,w_bad,b)
```

Считает те же числовые предсказания, но результат теперь является матрицей формы `(4, 1)`.

```python
print("yaht_bad: ", yaht_bad.shape)
```

Печатает новую форму.

```python
print("yaht_bad:    ", yaht_bad)
```

Печатает матрицу-столбец с четырьмя ответами.

```python
assert yaht.shape == (4,)
```

Проверяет ожидаемую форму результата с одномерными весами. Запятая в `(4,)` обязательна: так в Python записывается кортеж из одного элемента.

```python
assert yaht_bad.shape == (4,1)
```

Проверяет форму результата с весами-столбцом.

```python
print("Task 4 OK")
```

Сообщает, что обе проверки пройдены.

## Почему это важно

Если случайно вычесть массив `y` формы `(4,)` из `yaht_bad` формы `(4, 1)`, NumPy применит broadcasting и создаст матрицу `(4, 4)`, а не четыре попарные ошибки. Код не упадёт, но результат будет логически неправильным. Именно это показывает задача 5.
