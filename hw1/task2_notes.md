# Задача 2 — градиент функции двух переменных

Исходный код: [`task2.py`](task2.py)

## Что сделано

Для квадратичной функции двух переменных вычисляются аналитический и численный градиенты. Затем экспериментально проверяется геометрическое свойство: направление градиента даёт самый быстрый локальный рост функции среди направлений единичной длины.

## Фокус обучения

- частные производные;
- градиент как вектор;
- численная проверка градиента;
- нормализация вектора;
- производная по направлению;
- воспроизводимая генерация случайных чисел.

## Математика

```text
f(w₀, w₁) = w₀² + 3w₀w₁ + 2w₁²
∂f/∂w₀ = 2w₀ + 3w₁
∂f/∂w₁ = 3w₀ + 4w₁
```

В точке `(1, 2)` градиент равен `(8, 11)`. Сам градиент направлен к быстрейшему росту, а `-gradient` — к быстрейшему уменьшению функции.
