# Задача 2 — прямой проход, MSE и backpropagation

Исходный код: [`task2.py`](task2.py)

## Что сделано в задаче

Реализована маленькая нейронная сеть для одномерной регрессии:

```text
x → линейный слой → ReLU → линейный слой → y_hat
```

У сети один скрытый нейрон и четыре обучаемых параметра: `w1`, `b1`, `w2`, `b2`. Код выполняет прямой проход, считает среднеквадратичную ошибку и вручную получает градиенты всех параметров методом обратного распространения ошибки.

## Фокус обучения

- прямой проход `forward pass`;
- функция активации ReLU;
- функция потерь MSE;
- правило цепочки;
- обратное распространение ошибки;
- пакетная обработка нескольких объектов;
- смысл градиента каждого параметра.

## Формулы сети

```text
z1    = w1 * x + b1
h     = ReLU(z1) = max(0, z1)
y_hat = w2 * h + b2
L     = mean((y_hat - y)²)
```

Градиент показывает, как изменится `L` при небольшом увеличении соответствующего параметра. Чтобы уменьшать ошибку, позже параметры нужно двигать в направлении, противоположном градиенту.

### Прямой проход — строки 5–10

```python
def forward( params, x):
```

Объявляет функцию, которая прогоняет пакет `x` через сеть.

```python
    w1,b1,w2,b2 = params
```

Распаковывает четыре параметра сети в отдельные переменные.

```python
    z1 = w1 * x + b1
```

Выполняет первый линейный слой. Операция применяется сразу ко всем четырём элементам `x`.

```python
    h = np.maximum(0, z1)
```

Применяет ReLU: отрицательные значения заменяются нулями, положительные не меняются.

```python
    yhat = w2 * h +b2
```

Выполняет второй линейный слой и получает предсказания сети.

```python
    return z1, h, yhat
```

Возвращает промежуточные и финальные результаты. `z1` и `h` нужны далее для backpropagation.

### Функция потерь — строки 11–17

```python
def batch_loss(params, x,y):
```

Объявляет функцию ошибки для всего пакета данных.

```python
    z1,h,yhat= forward(params,x)
```

Выполняет прямой проход. В этой функции реально нужен только `yhat`, но остальные результаты также распаковываются.

```python
    assert yhat.shape == y.shape
```

Защищает от случайного несовпадения форм предсказаний и целей.

```python
    summ =0
```

Создаёт переменную для суммы. Эта строка не обязательна, потому что на следующей строке значение сразу перезаписывается.

```python
    summ = np.sum((yhat - y)**2)
```

Находит ошибку каждого объекта, возводит её в квадрат и суммирует квадраты.

```python
    L = (1/len(y))*summ
```

Делит сумму на число объектов и получает MSE — среднюю квадратичную ошибку.

```python
    return L
```

Возвращает одно число — значение функции потерь.

### Ручной backpropagation — строки 18–29

```python
def batch_gradients(params, x,y):
```

Объявляет функцию вычисления градиентов для всего пакета.

```python
    w1, b1,w2,b2 = params
```

Распаковывает параметры. Значение `b2` напрямую в формулах ниже не используется, но входит в `forward`.

```python
    z1,h,yhat = forward(params, x)
```

Снова выполняет прямой проход и сохраняет промежуточные значения для правила цепочки.

```python
    N = len(x)
```

Сохраняет размер пакета. Здесь `N = 4`.

```python
    g_yhat = 2/N * (yhat - y)
```

Вычисляет производную MSE по каждому предсказанию: `∂L/∂y_hat = 2(y_hat-y)/N`.

```python
    g_w2 = np.sum(g_yhat * h)
```

Считает `∂L/∂w2`. Так как `y_hat = w2*h+b2`, локальная производная по `w2` равна `h`; вклады всех объектов суммируются.

```python
    g_b2 = np.sum(g_yhat * 1)
```

Считает `∂L/∂b2`. Производная выражения `w2*h+b2` по `b2` равна `1`. Умножение на `1` можно было опустить.

```python
    g_h = g_yhat * w2
```

Передаёт градиент от выхода назад к скрытому значению `h`: `∂y_hat/∂h = w2`.

```python
    g_z1 = g_h * (z1> 0).astype(float)
```

Проходит назад через ReLU. Её производная равна `1` при `z1 > 0` и `0` при `z1 < 0`. В точке ноль обычно по соглашению берут `0`.

```python
    g_w1 = np.sum(g_z1 * x)
```

Считает `∂L/∂w1`. Для `z1 = w1*x+b1` производная по `w1` равна `x`.

```python
    g_b1 = np.sum(g_z1 * 1)
```

Считает `∂L/∂b1`. Производная `z1` по смещению равна `1`.

```python
    return np.array([g_w1, g_b1, g_w2, g_b2])
```

Возвращает градиенты в том же порядке, в котором хранятся параметры. Совпадение порядка критически важно для будущего обновления.

## Как читать отрицательные градиенты

Все начальные градиенты отрицательны. Обновление градиентного спуска имеет вид `parameter = parameter - eta * gradient`. Поэтому вычитание отрицательного числа увеличит параметры. Это логично: начальные предсказания ниже правильных ответов.
