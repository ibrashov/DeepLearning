# Задача 1 — перцептрон для AND и XOR

Исходный код: [`task1.py`](task1.py)

## Что сделано в задаче

С нуля реализован бинарный перцептрон. Он обучается на таблицах истинности двух логических функций:

- `AND`: единица получается только для пары `(1, 1)`;
- `XOR`: единица получается, когда входы различаются.

После обучения код выводит параметры модели, число ошибок на каждой эпохе, строит график и проверяет, что `AND` выучен правильно. Главный результат: один линейный перцептрон решает `AND`, но не может решить `XOR`, потому что классы XOR нельзя разделить одной прямой.

## Фокус обучения

- устройство простейшего искусственного нейрона;
- линейная комбинация `z = X @ w + b`;
- пороговая функция активации;
- правило обновления весов перцептрона;
- эпохи и ошибки классификации;
- линейная разделимость данных;
- разница между `AND` и `XOR`.

## Математика

Для одного объекта с признаками `x` перцептрон считает:

```text
z = w · x + b
prediction = 1, если z > 0, иначе 0
```

Если ответ неправильный:

```text
error = y - prediction
w = w + learning_rate * error * x
b = b + learning_rate * error
```

`w` поворачивает разделяющую прямую, а `b` сдвигает её.

### Получение предсказаний — строки 11–14

```python
def predict(X,w,b):
```

Объявляет функцию предсказания. Она получает объекты `X`, веса `w` и смещение `b`.

Для всех объектов сразу вычисляет линейную комбинацию. Оператор `@` умножает матрицу `X` формы `(4, 2)` на вектор `w` формы `(2,)`. Получается четыре значения `z`.


Сравнивает каждое `z` с нулём. Булевы значения `True/False` преобразуются в целые `1/0`.

### Обучение перцептрона — строки 15–31

```python
def train_perceptron(X,y, eta=0.5, max_epochs = 20):
```

Объявляет функцию обучения. `eta` — скорость обучения, а `max_epochs` — максимальное число полных проходов по данным.

```python
    w = np.zeros(2)
```

Создаёт два начальных веса, равных нулю: по одному на каждый входной признак.

```python
    b = 0.0
```

Задаёт начальное смещение.

```python
    mistake_per_epoch = []
```

Создаёт список, в котором будет храниться число ошибок каждой эпохи.

```python
    for epoch in range(max_epochs):
```

Запускает не более `max_epochs` полных проходов по обучающей выборке. Переменная `epoch` содержит номер эпохи, хотя далее явно не используется.

```python
        mistakes = 0
```

В начале эпохи обнуляет её счётчик ошибок.

```python
        for i in range(len(X)):
```

По очереди перебирает все четыре обучающих объекта.

```python
            z = w @ X[i]+b
```

Считает взвешенную сумму для одного объекта `X[i]`.

```python
            y_pred = 1 if z>0 else 0
```

Применяет порог и получает класс `0` или `1`.

```python
            err = y[i] - y_pred
```

Считает ошибку ответа. Она равна `1`, если нужно поднять ответ; `-1`, если нужно опустить; `0`, если ответ правильный.

```python
            w += eta*err*X[i]
```

Обновляет веса по правилу перцептрона. При `err == 0` веса не меняются.

```python
            b += eta*err
```

Тем же принципом обновляет смещение.

```python
            mistakes +=int( err != 0)
```

Выражение `err != 0` показывает, была ли ошибка. После преобразования в `int` к счётчику добавляется `1` или `0`.

```python
        mistake_per_epoch.append(mistakes)
```

После прохода по всем объектам сохраняет число ошибок эпохи.

```python
        if (mistakes == 0):
```

Проверяет, классифицированы ли все обучающие объекты правильно.

```python
            break
```

Досрочно завершает обучение, если ошибок больше нет.

```python
    return w,b,mistake_per_epoch
```

Возвращает обученные веса, смещение и историю ошибок.
