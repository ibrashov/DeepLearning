# Задача 3B — обучение градиентным спуском

Исходный код: [`task3B.py`](task3B.py)

## Что сделано в задаче

Сеть из задачи 2 обучается на данных `y = 2x + 1`. Сначала выполняется один шаг градиентного спуска и сравнивается loss до и после него. Затем выполняются 200 обновлений, сохраняется история функции потерь, выводятся финальные предсказания и строится кривая обучения.

## Фокус обучения

- обновление `params = params - eta * gradients`;
- смысл learning rate;
- многократный цикл обучения;
- пересчёт градиента после изменения параметров;
- история loss и кривая обучения;
- автоматическая проверка улучшения модели.

## Алгоритм

```text
1. Посчитать loss и градиенты.
2. Сдвинуть параметры против градиента.
3. Для новых параметров снова посчитать градиенты.
4. Повторить много раз.
```

Если `eta` слишком большая, loss может колебаться или расти. Если слишком маленькая — обучение будет очень медленным.

## Тонкость реализации

Переменная `gradients` перед циклом уже содержит градиент для `params0`, поэтому первая итерация корректна. Однако код легче читать и безопаснее изменять, если вычислять градиент внутри цикла перед обновлением:

```python
for step in range(200):
    gradients = batch_gradients(params, x, y)
    params = params - eta * gradients
    current_loss = batch_loss(params, x, y)
    loss_history.append(current_loss)
```
